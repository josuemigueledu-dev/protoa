# Orbital Glass (owner's reference, Oct 25, 2026)

A version of the app the owner sent as a zip. These files are kept here **for reference only**: `orbital.css` (the design layer) and `home.js` (the orb's dock on Today with milestones on an orbit). The rest of that zip matched the app's own files.

What it does: dark first, a near-black room lit by the orb, light flowing along curves, the orb docked on Today with milestone satellites, monospace readouts for numbers, light Sora for German, and a first-run "Guten Tag. Ich bin Protoa."

Status: **not a picked direction.** The visual design of the app is halted while the owner and the headmaster brainstorm mock-ups (see issue #1). Don't build from this until the owner picks it.
